## 目の前の色を、そのままパレットに

カメラをかざすだけで、目の前にあるモノの色をリアルタイムに読み取り、HEX / RGB / HSL のカラーコードと色名で採取できるアプリです。

## 主な機能

- **カメラでライブ採取**: 画面中央の色をリアルタイム表示。シャッターで色を固定して、そのままパレットに保存
- **写真から採取**: 保存済みの写真をタップして、好きな場所の色を抽出（無料は 1 回のお試し。続けて使うには有料プランが必要です）
- **カラーコード表示**: HEX / RGB / HSL に対応。ワンタップでコピー
- **色名がわかる**: CSS カラーネームの辞書から、いちばん近い色名を自動判定（JIS 慣用色名の辞書は有料プランで追加されます）
- **パレット管理**: 採取した色をパレットに保存（無料は 3 色まで）。有料プランでは保存数の上限がなくなり、複数のパレットで整理して、PNG 画像や HEX テキストとして書き出せます

## プライバシー

採取した色やパレットはすべて端末内にのみ保存されます。カメラ・写真は色の抽出のためだけに端末内で処理され、外部へ送信されることはありません。無料版では Google AdMob による広告を表示します（有料プランのご購入で非表示）。
